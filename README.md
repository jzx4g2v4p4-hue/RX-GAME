# RX Counter POV

A first-person pharmacy counter game. Work from behind the bench, verify each patient, check allergies, pull stock, count tablets, print labels, scan barcodes, bag orders, and hand them off before the line loses patience.

## Gameplay

- Start a shift from the counter view.
- Ask for DOB and check the profile before filling.
- Pull the matching drug and strength from stock.
- Count the exact quantity on the tray.
- Print the label, scan the barcode, bag the order, and hand it off.
- Score points for clean workflow and lose points for errors or impatient patients.

## Run locally

```bash
npm install
npm run dev
```

The app runs with Vite and React.
